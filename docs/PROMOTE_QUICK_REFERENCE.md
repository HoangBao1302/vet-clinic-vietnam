# Quick Reference: Promote Users
**ThebenchmarkTrader** - Admin & Staff Promotion

---

## 🚀 Quick Commands

### Promote to Admin
```bash
curl -X POST https://yourdomain.com/api/admin/promote \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@thebenchmarktrader.com","secretKey":"PROMOTE_ADMIN_2024"}'
```

### Promote to Staff
```bash
curl -X POST https://yourdomain.com/api/admin/promote-staff \
  -H "Content-Type: application/json" \
  -d '{"email":"staff@thebenchmarktrader.com","secretKey":"PROMOTE_STAFF_2024"}'
```

---

## 🔑 Secret Keys

| Purpose | Secret Key | Location |
|---------|-----------|----------|
| **Promote to Admin** | `PROMOTE_ADMIN_2024` | Hardcoded in code |
| **Promote to Staff** | `PROMOTE_STAFF_2024` (default) | Can override in Vercel env |

---

## 📋 Steps

### First Admin Setup

1. **Register** at `/register` with email: `admin@thebenchmarktrader.com`
2. **Verify email** (check inbox)
3. **Run promote command** (use cURL above)
4. **Login** at `/login` → Should access admin dashboard

### Add Staff User

1. **User registers** normally at `/register`
2. **Run promote-staff command** (use cURL above)
3. **User logs in** → Can manage blog posts

---

## 🔒 Security Tips

1. ✅ Change `PROMOTE_STAFF_SECRET` in Vercel to custom value
2. ✅ Use environment variables (not hardcoded)
3. ✅ Delete promote endpoints after first admin (optional)
4. ✅ Never commit secrets to Git
5. ✅ Rotate secrets every 3-6 months

---

## 🐛 Troubleshooting

**"Invalid secret key"**
→ Check spelling, case-sensitive

**"User not found"**
→ User must register first at `/register`

**Promoted but can't access admin**
→ Logout and login again, clear cache

**Check user role in MongoDB**
→ MongoDB Atlas → users collection → Find by email
